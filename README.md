## 📊 Dataset

**Dataset Name:** DataCo Smart Supply Chain for Big Data Analysis

**Source:** [Kaggle – DataCo Smart Supply Chain Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)

The original dataset contains approximately 180,519 records and 53 columns covering various aspects of supply chain operations, including orders, shipping, delivery status, and product categories.

For this project, relevant shipping and delivery fields were selected for focused analysis.

### Data Preparation Summary

* Selected relevant order, shipping, delivery status, shipping mode, and product category columns.
* Cleaned and processed the data using Python and Pandas.
* Removed duplicate records and validated date fields.
* Created `Shipping Delay` and `Shipping Performance` columns.
* Prepared the final dataset for SQL analysis and Power BI visualization.

**Final Dataset:** 48,301 records and 10 columns.

**Note:** The reported metrics and findings in this project are based on the selected and cleaned dataset, not the entire original dataset.
